# 星屑集 — 网站说明文档

## 一、网站简介

**星屑集**是一个个人收藏展示网站，展示图片、音乐、番剧和游戏收藏。

- 线上地址：https://026924.xyz
- GitHub 仓库：https://github.com/chuxiang486/xingxueji
- 部署平台：Cloudflare Pages（Git push 自动构建）
- 音乐存储：七牛云对象存储

---

## 二、技术架构

```
用户浏览器
    │
    ▼
Cloudflare Pages（CDN 边缘节点）
    │
    ├── 静态文件（HTML/CSS/JS/图片）→ 直接返回
    │
    ├── /music/* 请求 → Pages Functions 代理 → 七牛云
    │
    └── 其他请求 → 直接返回对应文件
```

## 三、核心功能说明

### 3.1 音乐播放系统

- **全局播放器**：`PlayerContext` 管理播放状态，任何组件都能控制播放
- **底部播放条**：`PlayerBar` 显示当前歌曲、进度、音量控制
- **音乐代理**：`_middleware.js` 拦截 `/music/*` 请求，代理到七牛云
  - 为什么需要代理：七牛有防盗链，只允许特定 Referer
  - 中间件设置正确的 Referer 头，转发 Range 请求（支持拖动进度条）

### 3.2 图片画廊

- 分类筛选（全部/游戏/动漫/其他）
- 点击图片打开 Lightbox 大图预览
- 键盘左右键切换、Esc 关闭
- 懒加载优化

### 3.3 视觉效果

- 星空背景（纯 CSS 动画）
- 鼠标跟随光效
- 滚动渐入动画（IntersectionObserver）
- 开屏加载动画
- 彩蛋：按 Konami Code（↑↑↓↓←→←→BA）触发

### 3.4 留言板

- 使用 Twikoo 开源评论系统
- 后端部署在 Cloudflare Workers（twikoo.026924.xyz）
- 前端动态加载，不影响首屏速度

## 四、常见修改

### 修改标题

- 网站标题（浏览器标签）：`index.html` 的 `<title>`
- 首屏大标题：`src/components/Hero.jsx`

### 修改样式

| 用途 | 值 | 文件 |
|------|-----|------|
| 页面背景 | `#0a0a14` | `App.css` |
| 强调色（紫色） | `rgba(140,120,220,...)` | 各组件 CSS |

### 添加新区块

1. 新建 `src/components/YourBlock.jsx` 和 `.css`
2. 在 `App.jsx` 中 import 并放到合适位置
