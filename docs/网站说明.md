# 星屑集 — 网站说明文档

## 一、网站原理

### 技术架构

```
xingxueji/                  ← 项目根目录
├── index.html              ← 入口 HTML，定义页面标题和挂载点
├── package.json            ← 项目配置（依赖、脚本命令）
├── vite.config.js          ← Vite 构建工具配置
├── public/                 ← 静态资源（直接复制到最终产物）
│   └── images/             ← 图片文件放在这里
└── src/                    ← 源代码目录
    ├── main.jsx            ← 程序入口，把 App 渲染到页面
    ├── App.jsx             ← 主组件，组合所有区块
    ├── App.css             ← 全局样式（背景色、字体、滚动行为）
    ├── data/               ← 数据文件（改内容只动这里）
    │   ├── images.js       ← 图片数据
    │   └── music.js        ← 音乐数据
    ── components/         ← 页面组件（每个区块一个文件夹对）
        ├── Navbar.jsx/css  ← 顶部导航栏
        ├── Hero.jsx/css    ← 顶部星空标题区
        ├── Gallery.jsx/css ← 图片画廊
        ── Music.jsx/css   ← 音乐列表
        └── Footer.jsx/css  ← 底部信息
```

### 运行流程

1. 你在终端执行 `npm run dev`
2. Vite 启动一个本地开发服务器（默认 `http://localhost:5173/`）
3. 浏览器访问这个地址，Vite 实时把 `src/` 里的代码转换成浏览器能运行的格式
4. 你修改任何 `.jsx` 或 `.css` 文件，保存后浏览器自动刷新

### 核心概念

- **组件（Component）**：每个 `.jsx` 文件是一个页面区块，比如 Hero 是标题区、Gallery 是图片区。它们像积木一样在 `App.jsx` 里拼在一起。
- **数据驱动**：图片和音乐的内容都存在 `src/data/` 下的 JS 文件里。页面根据这些数据自动生成，你不需要改 HTML。
- **样式隔离**：每个组件有自己的 `.css` 文件，互不干扰。

## 二、常见修改指南

### 1. 添加新图片

**步骤：**
1. 把图片文件放到 `public/images/` 文件夹
2. 打开 `src/data/images.js`，在数组里加一条：

```js
{
  id: 4,                          // 序号，不重复即可
  src: '/images/你的文件名.jpg',   // 路径以 /images/ 开头
  category: '游戏',                // 分类：游戏 / 动漫 / 其他
  title: '图片标题',               // 鼠标悬停时显示的文字
}
```

3. 保存文件，浏览器自动刷新

### 2. 添加/修改歌曲

打开 `src/data/music.js`，在 `songs` 数组中添加或修改：

```js
{
  id: 67,                          // 序号，不重复即可
  title: '歌曲名',
  artist: '歌手名',
  category: '治愈/温柔',            // 分类见下方说明
}
```

**分类可选值：**
- `治愈/温柔`
- `燃/力量`
- `抒情/伤感`
- `轻快/日常`

如果想新增分类，需要同时修改 `musicCategories` 数组：
```js
export const musicCategories = ['全部', '治愈/温柔', '燃/力量', '抒情/伤感', '轻快/日常', '你的新分类']
```

### 3. 修改 QQ 音乐歌单链接

打开 `src/data/music.js`，修改最后一行：
```js
export const qqMusicPlaylist = '你的新链接'
```

### 4. 修改标题或副标题

- **网站标题**（浏览器标签页）：编辑 `index.html` 中的 `<title>` 标签
- **Hero 大标题**：编辑 `src/components/Hero.jsx` 中的 `<h1>` 内容
- **Hero 副标题**：编辑 `src/components/Hero.jsx` 中的 `<p>` 内容
- **Footer 文字**：编辑 `src/components/Footer.jsx`

### 5. 修改颜色/样式

每个组件的样式在对应的 `.css` 文件中。几个关键颜色：

| 用途 | 当前值 | 文件 |
|------|--------|------|
| 页面背景 | `#0a0a14` | `src/App.css` |
| Hero 背景渐变 | `#1a1a2e → #0d0d1a → #050510` | `src/components/Hero.css` |
| 文字主色 | `#e8e6f0` | 各组件 CSS |
| 文字次要色 | `rgba(200,195,220,0.6)` | 各组件 CSS |
| 强调色（紫色） | `rgba(140,120,220,...)` | `Gallery.css` / `Music.css` |

如果想整体换色调，主要改 `App.css` 的 `body` 背景色和各组件中的紫色相关值。

### 6. 添加新区块

1. 在 `src/components/` 下新建 `YourBlock.jsx` 和 `YourBlock.css`
2. 在 `src/App.jsx` 中引入并放到合适位置：

```jsx
import YourBlock from './components/YourBlock'

function App() {
  return (
    <div className="app">
      <Navbar />
      <Hero />
      <Gallery />
      <YourBlock />   {/* 加在这里 */}
      <Music />
      <Footer />
    </div>
  )
}
```

## 三、常用命令

在项目目录 `xingxueji/` 下执行：

| 命令 | 作用 |
|------|------|
| `npm run dev` | 启动开发服务器（开发时用） |
| `npm run build` | 打包成静态文件（部署时用） |
| `npm run preview` | 预览打包后的效果 |
