## 五、关键技术实现

### 5.1 音乐代理

**问题**：七牛云设置了防盗链，只允许 `Referer: http://music.026924.xyz/` 的请求。

**解决方案**：Pages Functions 中间件拦截 `/music/*` 请求，代理到七牛云：

```javascript
// functions/_middleware.js
if (url.pathname.startsWith('/music/')) {
  const qiniuUrl = `http://music.026924.xyz/${filename}`
  const headers = new Headers()
  headers.set('Referer', 'http://music.026924.xyz/')  // 防盗链白名单
  const range = request.headers.get('Range')
  if (range) headers.set('Range', range)  // 支持拖动进度条
  // 不转发其他浏览器头（Origin, Sec-Fetch-Site 等），七牛会拒绝
  const response = await fetch(qiniuUrl, { headers })
  // 只对成功响应设置缓存，避免缓存 403 错误
  if (response.ok) {
    newHeaders.set('Cache-Control', 'public, max-age=31536000')
  }
  return new Response(response.body, { status: response.status, headers: newHeaders })
}
```

### 5.2 全局播放器

使用 React Context 实现跨组件状态共享：

```
PlayerProvider（包裹整个应用）
  ├── Music      → 调用 playSong() 设置播放
  ├── PlayerBar  → 读取 currentSong 显示信息
  └── <audio>    → 全局唯一的 audio 标签
```

## 七、遇到的问题与解决方案

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 网站白屏 | `_redirects` 用空格分隔，Cloudflare 要求 Tab | 改用细粒度路由规则，最终移除（不需要客户端路由） |
| 音乐播放 403 | 七牛防盗链，Referer 不在白名单 | 中间件设置正确 Referer：`http://music.026924.xyz/` |
| 代理后仍 403 | 浏览器头（Origin 等）被七牛拒绝 | 中间件只转发 Referer 和 Range |
| 修复后仍无法播放 | 旧的 403 响应被缓存 1 年 | 只对 200 响应设置缓存头 |
| HEAD 请求 403 | 七牛对 HEAD 校验更严格 | 不影响实际使用，浏览器用 GET/Range |
| 部署后未更新 | Vite 哈希碰撞，Cloudflare 缓存旧文件 | main.jsx 加版本标记 + Purge Cache |
| git push 失败 | 国内网络限制 | 使用代理或 GitHub API |

## 八、存储架构

| 内容 | 存储位置 | 原因 |
|------|----------|------|
| 代码 | GitHub | 版本管理 + 自动部署 |
| 图片（500KB） | GitHub → Cloudflare CDN | 体积小，直接放仓库 |
| 音乐（~1.5GB） | 七牛云 | 体积大，需要 CDN + Range 支持 |
| 评论数据 | Cloudflare Workers KV | Twikoo 后端 |

**七牛云免费额度**：10GB 存储，目前使用约 1.5GB。

## 十、简历描述参考

### 项目名称
星屑集 — 个人收藏展示网站

### 项目描述
基于 React + Vite 构建的个人收藏展示网站，包含图片画廊、音乐播放器（263 首）、番剧/游戏收藏区、留言板等功能模块。采用暗色主题设计，实现星空背景、滚动动画等视觉效果。音乐文件存储于七牛云，通过 Cloudflare Pages Functions 代理访问以解决防盗链问题。

### 技术要点
- React 19 函数组件 + Hooks，Context API 实现全局播放器状态管理
- Vite 8 构建，HMR 热更新开发体验
- HTML5 Audio API 实现音乐播放，支持进度拖动、上下首切换
- Cloudflare Pages Functions 实现边缘代理，解决七牛云防盗链问题
- 精简请求头转发（仅 Referer + Range），避免七牛安全策略拒绝
- 区分成功/失败响应的缓存策略，避免错误响应被长期缓存
- IntersectionObserver 实现滚动渐入动画
- 数据驱动设计，内容与组件分离
- 开发自动化脚本（Node.js）批量添加音乐/图片
- 集成 Twikoo 开源评论系统

### 职责描述
独立完成项目的设计、开发、调试与部署全流程。解决 Cloudflare Pages SPA 路由、七牛云防盗链代理、CDN 缓存等多个技术问题。
