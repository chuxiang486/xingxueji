# 壁纸生成与图片优化

生成方式：内置 image_gen 工具。以下三张壁纸替换了壁纸专区原来的两张；PNG 原图保存在 public/wallpapers/，WebP 预览保存在 public/thumbnails/wallpapers/。实际分辨率由 imageVariants.js 记录，未将图像放大为虚标的 2K/4K。

修改或新增原图后运行 `npm run images:build`，更新 360/720 像素画廊预览与 480/960/原尺寸壁纸预览；`npm run build` 使用已生成并随项目保存的资源。

画廊使用本地 WebP 缩略图、srcSet 与固有宽高；大图预览保持原图地址。壁纸展示使用 WebP，下载使用本地 PNG。

音乐列表使用稳定的歌曲/播放状态快照，进度、音量和时长变化不会改变该快照。筛选和分组仅在对应输入变化时重新计算。
