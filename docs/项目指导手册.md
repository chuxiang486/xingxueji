# 星尘集项目指导手册

## 从哪里进入

正式站为 `https://026924.xyz/`，内容管理入口为 `/admin/`。本地和正式站使用各自的数据库和管理密钥。日常修改请先看浏览器地址栏，确认正在编辑哪个站点。后台保存后，刷新同一站点的首页查看效果。

## 日常维护

进入后台，输入对应环境的管理密钥。在“管理栏目”选择栏目，搜索并点击已有条目，或点击“新增条目”。填完后点击“保存”。要删除时先检查标题，再确认删除。删除图库或音乐条目只移除展示记录，原文件仍保存在原来的位置。

| 栏目 | 编辑内容 | 保存后的检查 |
| --- | --- | --- |
| 图库 | 标题、原图地址、分类、作品、角色 | 按分类找到图片，点开大图 |
| 壁纸 | 名称、原图地址、分类、分辨率 | 浏览壁纸并打开原图 |
| 音乐 | 歌名、歌手、分类、音频地址 | 按歌名搜索，播放并拖动进度条 |
| 追番 | 名称、观看状态、1–10 分评分、短评 | 查看首页“我的收藏” |
| 游戏 | 名称、平台、游玩时长、备注 | 查看首页游戏卡片 |

图片和音频通过链接添加。先把文件放在可公开访问的位置，再填写 HTTPS 地址。已有站内资源可使用 `/images/文件名.webp`、`/wallpapers/文件名.png` 或 `/music/文件名.mp3`。访客必须能直接访问该地址。若出现“记录已更改”，先记下自己的修改，点击“重新加载”，对照最新内容再保存。

## 在本机运行

在项目根目录使用项目支持的 Node.js 版本（推荐 Node 22.13+ 的 22.x 或当前项目已验证的 26.x）。首次安装运行 `npm ci`。本地密钥位于根目录 `.env.local` 的 `ADMIN_TOKEN` 项，只复制等号后面的值到登录框。更改环境变量后重启开发服务。

```powershell
npm run dev -- --host 127.0.0.1 --port 5192 --strictPort
```

打开 `http://127.0.0.1:5192/admin/`。本机数据库位于 `.wrangler/catalog.sqlite`。做本地备份时先关闭开发服务，再复制数据库。提交前运行 `npm test`、`npm run lint`、`npm run build`。

## 正式部署与数据

GitHub 仓库为 `chuxiang486/xingxueji`，`main` 连接 Cloudflare Pages 项目 `xingxueji7`。构建命令为 `npm run build`，静态输出目录为 `dist`；仓库根目录的 `functions/` 提供同源 API。只复制 `dist` 到普通静态服务器无法提供后台写入功能。

1. 在有权限的 Cloudflare 账号中选择项目的生产环境。首次启用时创建专用 D1 数据库，例如 `xingxueji-catalog`。对空库依次执行下面两条迁移命令。已有库先检查表名；若已有 `songs`，跳过第一条。迁移前先备份已有生产库。

   ```powershell
   npx wrangler d1 execute xingxueji-catalog --remote --file migrations/0001_songs.sql
   npx wrangler d1 execute xingxueji-catalog --remote --file migrations/0002_content.sql
   ```

2. 在 Pages 生产环境绑定该 D1 库，变量名为 `DB`。在同一环境的加密 Secret 中设置独立的 `ADMIN_TOKEN`，保存在自己的密码管理器。不要使用 `VITE_` 前缀，不要把密钥粘贴进 Git、手册、聊天或截图。
3. 推送已检查的代码至 `main`，或在变更绑定后重新部署。等待该次 Pages 部署成功。访问 `/api/songs`、`/api/content?section=gallery` 和 `/admin/`。未登录访问 `/api/songs?manage`，返回 401 表示已启用身份检查；503 表示后台配置或数据库仍需检查。用生产密钥登录后确认五个栏目均可读取。
4. 后续日常编辑直接写入 D1，无需重新发布。代码回退不会撤销数据库操作。下载数据库备份时请存放在仓库外。本地 SQLite、生产密钥和本地编辑记录均不随 Git 发布。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 后台提示密钥无效 | 确认站点环境，重新输入对应密钥。如果轮换了线上 Secret，重新部署后再登录 |
| 前台有内容，但后台显示尚未配置 | 公开页面可读取内置内容。检查生产 `DB` 绑定、`ADMIN_TOKEN` Secret，并重新部署 |
| 管理页可打开，某个栏目加载失败 | 确认绑定到了预期数据库，并检查 `songs` 与 `content_changes` 两张表 |
| 保存后正式站没有变化 | 检查是否误在本地或预览站编辑，再刷新正式站 |
| 换图后图片不显示 | 直接打开原图网址，检查文件路径、访问权限和图床防盗链设置 |
