# 星屑集 — 内容更新指南

## 一、添加新图片

### 1. 准备图片文件
- 格式：`.webp`（推荐）或 `.jpg`、`.png`
- 大小：建议单张不超过 5MB
- 将图片文件放入 `public/images/` 目录

### 2. 编辑图片数据
打开 `src/data/images.js`，在 `images` 数组中添加一条记录：

```js
export const images = [
  {
    id: 1,
    src: './images/20200324171249_spioe.webp',
    category: '游戏',
    title: '明日方舟',
  },
  {
    id: 2,
    src: './images/OIP-C.webp',
    category: '游戏',
    title: '明日方舟',
  },
  // 在这里添加新图片 ↓
  {
    id: 3,                    // id 递增，不重复即可
    src: './images/你的图片名.webp',  // 文件名要和 public/images/ 里的一致
    category: '动漫',          // 分类必须是 imageCategories 中已有的
    title: '图片标题',
  },
]
```

### 3. 添加新分类（如果需要）
在 `imageCategories` 数组中添加：

```js
export const imageCategories = ['全部', '游戏', '动漫', '其他', '新分类']
```

> 注意：`全部` 是默认的，不要删。新分类名要和图片的 `category` 字段一致。

## 二、添加新歌曲

打开 `src/data/music.js`，在 `songs` 数组中添加：

```js
{ id: 67, title: '歌曲名', artist: '歌手', category: '治愈/温柔' },
```

- `id`：递增，不重复
- `category`：必须是 `musicCategories` 中已有的分类
- 目前分类：`治愈/温柔`、`燃/力量`、`抒情/伤感`、`轻快/日常`

添加新分类同理，修改 `musicCategories` 数组即可。

---

## 三、部署更新

改完代码后，执行以下步骤：

```bash
# 1. 查看改动
git status

# 2. 添加所有改动
git add .

# 3. 提交
git commit -m "添加新图片/歌曲：xxx"

# 4. 推送（Cloudflare Pages 会自动构建部署）
git push origin main
```

推送成功后，等 1-2 分钟，刷新 https://xingxueji7.pages.dev/ 即可看到更新。

## 四、本地预览

部署前可以先在本地查看效果：

```bash
npm run dev
```

浏览器打开 http://localhost:5173 预览。

## 五、文件结构速查

```
xingxueji/
├── public/images/        ← 图片文件放这里
├── src/data/
│   ├── images.js         ← 图片数据（路径、分类、标题）
│   └── music.js          ← 歌曲数据
├── src/components/       ← 页面组件（一般不用改）
└── vite.config.js        ← Vite 配置（一般不用改）
```
