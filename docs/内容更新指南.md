# 星屑集 — 内容更新指南

## 一、添加新图片（自动化）

### 使用脚本

```bash
# 1. 把图片放到 new-images/ 目录
#    文件名格式：分类-标题.webp（如：游戏-明日方舟.webp）
#    或直接命名（如：arknights-01.webp），脚本会自动猜分类

# 2. 运行脚本
node add-images.mjs
```

脚本会自动：
- 复制图片到 `public/images/`
- 更新 `src/data/images.js`（递增 ID、设置分类和标题）
- 把已处理文件移到 `new-images/done/`

支持格式：`.jpg` `.png` `.webp` `.gif`

### 手动添加

1. 把图片放到 `public/images/`
2. 编辑 `src/data/images.js`，加一条：

```js
{
  id: 6,                    // id 递增，不重复即可
  src: './images/文件名.webp',
  category: '游戏',          // 游戏 / 动漫 / 其他
  title: '图片标题',
}
```

3. 如需新分类，修改 `imageCategories` 数组（`全部` 不要删）

## 二、添加新歌曲（自动化）

### 使用脚本

```bash
# 1. 把 MP3 放到 new-songs/ 目录
#    文件名格式：歌手 - 歌名.mp3（如：周杰伦 - 晴天.mp3）

# 2. 运行脚本
node add-songs.mjs
```

脚本会自动：
- 上传 MP3 到七牛云
- 更新 `src/data/music.js`
- 把已上传文件移到 `new-songs/done/`

### 手动添加

1. 把 MP3 上传到七牛云
2. 编辑 `src/data/music.js`，加一条：

```js
{
  id: 264,
  title: '歌曲名',
  artist: '歌手',
  category: '治愈/温柔',
  url: '/music/文件名.mp3',
}
```

分类可选值：`治愈/温柔`、`燃/力量`、`抒情/伤感`、`轻快/日常`

## 三、部署更新

改完代码后：

```bash
git add .
git commit -m "添加新图片/歌曲：xxx"
git push origin main
```

Cloudflare Pages 会自动构建部署，等 1-2 分钟刷新 https://026924.xyz/ 即可。

## 五、文件结构速查

```
xingxueji/
├── add-images.mjs          ← 图片添加脚本
├── add-songs.mjs           ← 歌曲添加脚本
├── new-images/             ← 新图片暂放目录
├── new-songs/              ← 新歌曲暂放目录
├── public/images/          ← 图片文件（存在仓库里）
├── src/data/
│   ├── images.js           ← 图片数据
│   └── music.js            ← 歌曲数据（URL 指向七牛）
├── functions/
│   └── _middleware.js       ← 音乐代理（转发到七牛）
└── src/components/         ← 页面组件（一般不用改）
```
